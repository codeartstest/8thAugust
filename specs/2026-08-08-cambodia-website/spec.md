# Spec: About Cambodia Website

## Overview

A single-page static website about Cambodia, built with pure HTML/CSS/JS. No frameworks, no build tools, no external dependencies.

## Requirements

### REQ-1: Single-Page Layout
The website **shall** display a single HTML page containing all content sections in a vertical scroll layout.

### REQ-2: Navigation Bar
The website **shall** include a sticky navigation bar at the top with links to each content section.

### REQ-3: History Section
The website **shall** include a History section covering the Khmer Empire, French colonization, and modern Cambodia.

### REQ-4: Geography Section
The website **shall** include a Geography section covering location in Southeast Asia, borders, Mekong River, and Tonle Sap lake.

### REQ-5: Population Section
The website **shall** include a Population section covering approximate population (~17 million), demographics, and ethnic groups.

### REQ-6: Language Section
The website **shall** include a Language section covering the Khmer script overview and common phrases.

### REQ-7: Footer
The website **shall** include a footer with copyright notice and navigation links.

### REQ-8: Responsive Design
The website **shall** be responsive, displaying a horizontal navigation bar on desktop and a hamburger menu on mobile screens.

### REQ-9: Color Palette
The website **shall** use a Cambodia-themed color palette: deep red (#9E1B32), gold (#D5A021), and white (#FFFFFF).

### REQ-10: No External Dependencies
The website **shall not** use any external libraries, CDNs, frameworks, or build tools.

## Constraints

- Frontend only — no backend, no server-side logic
- Three files maximum: index.html, styles.css, script.js
- Content is static (hardcoded, no API calls)
